# Glimt 1.5.0 (26/10/2026)

Glimt now works with AI agents: they can start breathing sessions and design breathing visuals made just for you. This release also adds two new breathing presets.

## New features

  - Built-in MCP server: AI agents like Claude can start breathing sessions and adjust your settings. Turn it on and manage access in the new Agent & MCP section of Settings
  - The Glimt agent plugin for Claude Code: connects Claude to Glimt and teaches it to design breathing visualizations. Install it in Claude Code with:

    ```
    /plugin marketplace add yornaath/glimt-agent-plugin
    /plugin install glimt-app-agent-plugin@glimt
    ```

    Source and docs: [github.com/yornaath/glimt-agent-plugin](https://github.com/yornaath/glimt-agent-plugin)
  - Custom breathing visualizations: ask your agent to design your own 2D or 3D breathing animation, then preview, rename or delete it from Settings
  - Two new built-in presets: Trikona A (an easy hold on the inhale) and Trikona B (an easy hold on the exhale)
  - Update notifications: when a new version is ready, Glimt lets you restart now or later

## Improvements

  - Settings update live when an agent changes something
  - Built-in presets, and presets in use, can no longer be deleted by accident
  - A cleaner breath counter on the orbs and the countdown
  - A softer edge on the micro reminder breath

## Bug Fixes

 - Fixed the size of the flat orb in the visuals preview
