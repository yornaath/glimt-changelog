# Glimt 1.2.0 (18/09/2026)

Meet the new 3D orb — a softer, more alive breathing visual, now the default — plus a handful of Windows fixes.

## New feature

  - **3D Orb visualization** — a new, gently shaded 3D orb that breathes with you. It's now the default visual, and you can switch back to the classic flat orb anytime from Settings → Visuals.

## Improvements

  - The "Next" button no longer shows during a playlist unless you're in full screen, keeping the breathing view clean.

## Bug Fixes

  - Playlists now use the get-ready countdown you set, instead of always counting down from 8 seconds.
  - **Windows:** the micro-breath widget no longer steals focus from what you're working on, and double-clicking to close it works again.
  - **Windows:** fixed the breathing reminder notification showing a wrong background.
