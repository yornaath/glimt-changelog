# Glimt 1.4.0 (13/10/2026)

A calmer, clearer Settings window, streaks set up from day one, and a little something hidden for the curious.

## New features

  - Set up your daily streak goal during onboarding
  - A hidden surprise in Settings for those who like to explore ✨

## Improvements

  - Redesigned Settings: reorganised menu, tidier reminder and prompt options, and a new visuals section with a live preview
  - New sliders that are smoother to drag, with suggested minimum and maximum values for reminder intervals
  - Easier active hours setup
  - Toggles and segmented controls now share one consistent look
  - The "Coherence" preset is now called "Just Breathe (Coherence)"
  - The onboarding window now opens centered on screen
